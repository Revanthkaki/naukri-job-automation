## ✨ Features

- 🔐 **Auto-Login** - Automatically logs into your Naukri account
- 🔍 **Smart Job Search** - Searches and collects relevant job listings
- 📝 **AI-Powered Answers** - Uses Google Gemini AI to answer application questions professionally
- 🤖 **CAPTCHA Solving** - Automatically solves reCAPTCHA using 2Captcha service
- 📊 **Detailed Logging** - Tracks all applications and generates comprehensive reports
- ⏰ **Continuous Operation** - Runs in endless loop with configurable wait times
- 🎯 **Smart Filtering** - Automatically avoids already applied jobs
- 🚀 **Easy Setup** - Simple configuration with environment variables
- 📈 **Statistics Tracking** - Real-time monitoring of success/failure rates
- 🔒 **Stealth Mode** - Anti-detection measures to appear human-like


## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- **Python 3.8+** - [Download Python](https://www.python.org/downloads/)
- **Google Chrome** - [Download Chrome](https://www.google.com/chrome/)
- **Gemini API Key** - [Get API Key](https://makersuite.google.com/app/apikey)
- **2Captcha API Key** (Optional) - [Get API Key](https://2captcha.com/)
